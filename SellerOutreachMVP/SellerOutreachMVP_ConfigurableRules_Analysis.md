# SellerOutreachMVP_ConfigurableRules_Analysis

## 목적
- 후보 발굴 기준표, 점수표, 검수 체크리스트를 운영자가 직접 입력할 수 있는 구조를 정리한다.

## 왜 설정형이어야 하는가
- 카테고리마다 기준이 다르다.
- 운영 방식이 바뀔 수 있다.
- 코드를 고치지 않고도 기준을 조정할 수 있어야 한다.

## 운영자가 입력하는 3가지
### 후보 발굴 기준표
- 키워드
- 해시태그
- 시드 계정
- 제외 조건
- 최소 팔로워/게시물 수

### 점수표
- 판매자 여부 가점
- 아마존 적합도 가점
- 감점 규칙
- 등급 기준

### 검수 체크리스트
- 실제 판매 계정 여부
- 공개 연락 채널 존재 여부
- 민감 품목 여부
- 개인화 포인트 메모
