# SellerOutreachMVP_UIFlow_Analysis

## 목적
- 운영자가 화면을 어떤 순서로 사용하는지 흐름 중심으로 정리한다.

## 전체 화면 맵
- 대시보드
- 리드 리스트
- 리드 상세
- 검수 큐
- 아웃리치 큐
- CRM 보드
- 온보딩 상세
- 설정 페이지

## 대표 흐름
1. 대시보드에서 신규 리드 확인
2. 리드 리스트에서 후보 탐색
3. 리드 상세에서 점수와 근거 확인
4. 검수 큐에서 승인/보류/제외 결정
5. 아웃리치 큐에서 이메일 또는 DM 처리
6. CRM 보드에서 답장 이후 단계 관리
7. 온보딩 상세에서 진행 상황 기록
