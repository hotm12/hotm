# SellerOutreachMVP_DevSpec_Analysis

## 목적
- 개발 시작 전에 기능 범위, 역할, 원칙, 우선순위를 명확히 정리한다.

## MVP 목표
- 캠페인 설정
- 후보 발굴 기준 입력
- 리드 저장 및 점수화
- 검수 및 승인
- 아웃리치 큐 생성
- 답장과 CRM 관리
- 온보딩 상태 추적

## 사용자 역할
- 리서치 운영자: 후보 검수와 DM 수동 발송
- 아웃리치 담당자: 메시지 검토와 후속 대응
- 온보딩 담당자: 셀러 준비 상태 관리
- 관리자: 규칙, 템플릿, 권한 관리

## 포함 범위
- 캠페인/소스/필터 설정
- 점수표 및 체크리스트 설정
- 리드 리스트/상세/검수
- 메시지 초안 및 큐
- CRM 보드
- 온보딩 상태 관리

## 제외 범위
- 대량 자동 DM 발송
- 비공개 정보 수집
- 계약/정산 자동화
- 셀러 계정 및 상품 등록 자동화

## 성공 기준
- 리드가 `수집 -> 점수화 -> 검수 -> 발송 -> CRM -> 온보딩`으로 끊기지 않고 이어진다.
- 운영자가 화면에서 우선순위를 바로 판단할 수 있다.
- 재연락 금지 대상 관리가 가능하다.
