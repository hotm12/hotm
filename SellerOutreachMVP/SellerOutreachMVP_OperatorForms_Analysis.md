# SellerOutreachMVP_OperatorForms_Analysis

## 목적
- 운영자가 실제로 입력하는 폼을 화면/필드/검증 단위로 정리한다.

## 핵심 폼 목록
- 캠페인 생성/수정 폼
- 후보 소스 입력 폼
- 후보 필터 입력 폼
- 점수 규칙 세트 폼
- 점수 규칙 항목 폼
- 체크리스트 템플릿 폼
- 체크리스트 항목 폼
- 리드 검수 실행 폼
- 메시지 초안 승인 폼
- DM 수동 발송 처리 폼
- CRM 액션 입력 폼
- 온보딩 업데이트 폼

## 공통 원칙
- 필수 입력은 최소화
- 반복 입력은 템플릿화
- 저장 전 검증과 저장 후 미리보기 분리
- 변경 이력 보존
