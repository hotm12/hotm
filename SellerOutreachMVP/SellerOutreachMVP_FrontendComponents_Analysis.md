# SellerOutreachMVP_FrontendComponents_Analysis

## 목적
- 프론트엔드에서 필요한 공통/페이지별 컴포넌트를 정리한다.

## 공통 컴포넌트
- StatusBadge
- ScoreBadge
- RiskFlagList
- SearchSelect
- TagInput
- ChecklistRenderer
- DrawerPanel
- FilterSidebar

## 페이지별 컴포넌트
- 대시보드: KPI 카드, 작업 큐 패널
- 리드 리스트: 테이블, 빠른 미리보기 패널
- 리드 상세: 점수 패널, 검수 패널
- 검수 큐: 카드형 리스트
- 아웃리치 큐: 이메일/DM/후속 탭
- CRM 보드: 칸반 컬럼, 카드
- 온보딩: 체크리스트, 메모 패널
- 설정: 캠페인 폼, 규칙 폼, 체크리스트 폼
