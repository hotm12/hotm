# SellerOutreachMVP_API_Analysis

## 목적
- 기능별 API 범위를 정리한다.

## 캠페인/설정 API
- 캠페인 생성/수정/조회
- 후보 소스 CRUD
- 필터 CRUD
- 점수 규칙 CRUD
- 체크리스트 템플릿 CRUD

## 리드 API
- 리드 등록
- 리드 목록 조회
- 리드 상세 조회
- 승인/보류/제외

## 점수화 API
- 리드 점수 재계산
- 배치 점수 계산
- 점수 근거 조회

## 아웃리치 API
- 메시지 초안 미리보기
- 메시지 승인
- 이메일 발송
- DM 큐 등록

## CRM/온보딩 API
- 답장 등록/재분류
- 활동 기록 추가
- CRM 단계 이동
- 온보딩 시작/업데이트
